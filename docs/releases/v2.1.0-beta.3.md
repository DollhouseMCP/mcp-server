# DollhouseMCP v2.1.0-beta.3

Draft release notes for changes merged after `v2.1.0-beta.2`, through beta commit `d0278ad58d962a3386be34379475c40600c141a1`. This describes merged code; it does not announce publication, deployment, database-memory activation, or a vulnerability-free image.

## security

- Upgrade the MCP SDK to **1.31.0**, with regression coverage that stored OAuth client credentials and refresh tokens remain bound to their issuer rather than following a changed authorization server. Existing remote MCP bearer bridging is also covered. ([#3066](https://github.com/DollhouseMCP/mcp-server/pull/3066))
- Update application and browser sanitizer dependencies, including DOMPurify **3.4.16**, smol-toml **1.9.0**, Hono **4.13.7** and its Node adapter **1.19.15**. Refresh build/test dependency overrides and the Safety dependency to **^1.0.5**. ([#3070](https://github.com/DollhouseMCP/mcp-server/pull/3070), [#3077](https://github.com/DollhouseMCP/mcp-server/pull/3077))
- Harden container construction with a digest-pinned Node 24 Trixie base and selected supported Debian security updates. Keep Safety build dependencies out of production layers, update global npm dependency leaves in tooling images, and remove unused `infocmp` and `nsenter` executables from final runtime images. These are targeted changes, not a claim that every image advisory is resolved. ([#3059](https://github.com/DollhouseMCP/mcp-server/pull/3059), [#3067](https://github.com/DollhouseMCP/mcp-server/pull/3067), [#3068](https://github.com/DollhouseMCP/mcp-server/pull/3068), [#3081](https://github.com/DollhouseMCP/mcp-server/pull/3081))

## hosted/HTTP

- Keep accepted standalone SSE sessions alive during quiet agent work. Add configurable keepalive comments, stream lifetime and credential-expiry grace; closing the final stream starts the session idle grace. Quiet connected sessions renew runtime presence without counting heartbeats as user requests. ([#3061](https://github.com/DollhouseMCP/mcp-server/pull/3061))
- Stop delivering MCP payloads on a stream whose credential has expired, while allowing heartbeats during renewal grace. An authenticated POST can renew a stream only when its verified credential binding matches; messages dropped during expiry are not replayed, and renewal requests a tool-list resync. Add bounded stalled-stream closure and confirmed-presence-lease admission checks. ([#3061](https://github.com/DollhouseMCP/mcp-server/pull/3061))
- Add memory-aware graceful replacement: close mutation admission, retain admitted persistence work and owners, and refuse replacement when drain completion or clean process closure is unknown. Legacy `addEntry` replies wait for persistence. Supported hosted update/rollback scripts use a nonce-bound drain acknowledgement before a single TERM; shorter bounded closure polling retains the original deadline and refuses late success. This is drain/reconnect behavior, not zero downtime or automatic recovery. ([#3050](https://github.com/DollhouseMCP/mcp-server/pull/3050), [#3109](https://github.com/DollhouseMCP/mcp-server/pull/3109))

## OAuth

- Preserve requested offline access in supported embedded authorization flows by adding consent when appropriate. Refresh tokens still require client grant eligibility and user approval; signed requests and `prompt=none` are not silently rewritten. Document refresh-token rotation and client reconnect considerations. ([#3061](https://github.com/DollhouseMCP/mcp-server/pull/3061))
- Serialize OAuth helper PID publication and cleanup under the existing generation lock. A superseded helper cannot publish against a newer state generation; cleanup checks current generation and its own PID before removing files, while successful encrypted handoff remains available for parent import. ([#3116](https://github.com/DollhouseMCP/mcp-server/pull/3116))
- **Compatibility change for standalone helper integrations:** the detached helper now requires a nonempty flow ID **and matching prepared state**. Setting the environment variable alone is insufficient. Use the existing `setup_github_auth` controller, or participate in its coordinated preparation/handoff lifecycle; unscoped standalone invocation is refused before shared writes or GitHub polling. ([#3116](https://github.com/DollhouseMCP/mcp-server/pull/3116))

## Gatekeeper

- Classify Gatekeeper infrastructure operations before collecting active-element policies, keeping recovery infrastructure reachable when policy collection fails while retaining route and Gatekeeper enforcement. Permission prompts return a normal, audited denial when active-element policies cannot be collected; failure does not create an approval. ([#3126](https://github.com/DollhouseMCP/mcp-server/pull/3126))

## personas/memory

- Recover active personas after cache eviction using durable storage identity (file path or database UUID), rather than relying only on display-name lookup. Keep activation records tied to the resolved element; typed database reads also check element type. ([#3121](https://github.com/DollhouseMCP/mcp-server/pull/3121))
- Add guarded database-memory admission and conditional-update plumbing, with authenticated tenant binding retained across CRUD, agent execution, console, collection, portfolio, sync and deferred saves. Unknown modes or changed authority refuse rather than falling back to a root/file-backed manager; selected guarded indexes derive in RAM from their database source. ([#3012](https://github.com/DollhouseMCP/mcp-server/pull/3012), [#3014](https://github.com/DollhouseMCP/mcp-server/pull/3014), [#3015](https://github.com/DollhouseMCP/mcp-server/pull/3015), [#3023](https://github.com/DollhouseMCP/mcp-server/pull/3023), [#3029](https://github.com/DollhouseMCP/mcp-server/pull/3029), [#3032](https://github.com/DollhouseMCP/mcp-server/pull/3032), [#3034](https://github.com/DollhouseMCP/mcp-server/pull/3034), [#3035](https://github.com/DollhouseMCP/mcp-server/pull/3035), [#3037](https://github.com/DollhouseMCP/mcp-server/pull/3037), [#3042](https://github.com/DollhouseMCP/mcp-server/pull/3042))
- Refuse unsupported legacy writes, deferred mutations, maintenance and account-memory deletion cascades before destructive effects. Add read-fidelity qualification before guarded commit/startup, plus authenticated contention and compiled-restart tests. The initial guarded profile supports existing-owner, archive-free updates; create/delete/archive and unsupported export/upload paths remain refused. Merged plumbing does **not** enable or authorize a guarded-memory cohort: provisioning, writer exclusion, capacity, backup/rollback and activation qualification remain separate prerequisites. ([#3016](https://github.com/DollhouseMCP/mcp-server/pull/3016), [#3017](https://github.com/DollhouseMCP/mcp-server/pull/3017), [#3018](https://github.com/DollhouseMCP/mcp-server/pull/3018), [#3020](https://github.com/DollhouseMCP/mcp-server/pull/3020), [#3038](https://github.com/DollhouseMCP/mcp-server/pull/3038), [#3043](https://github.com/DollhouseMCP/mcp-server/pull/3043))

## CI/test

- Isolate required PostgreSQL integration shards and split Core unit selection into complementary Jest shards. Run storage crash/adoption/EOF proofs and helper/model qualification in their required serial lanes, retaining mandatory outcome checks. Enable integration-worker recycling. ([#3048](https://github.com/DollhouseMCP/mcp-server/pull/3048), [#3083](https://github.com/DollhouseMCP/mcp-server/pull/3083), [#3089](https://github.com/DollhouseMCP/mcp-server/pull/3089), [#3093](https://github.com/DollhouseMCP/mcp-server/pull/3093), [#3112](https://github.com/DollhouseMCP/mcp-server/pull/3112), [#3119](https://github.com/DollhouseMCP/mcp-server/pull/3119))
- Track original asynchronous test callbacks, admitted setup writes and owned child processes through teardown. Unsettled work retains resources and blocks later admission instead of pretending cleanup completed. Bound DELETE/RENAME read observers and reduce redundant Git-fixture subprocesses. ([#3039](https://github.com/DollhouseMCP/mcp-server/pull/3039), [#3045](https://github.com/DollhouseMCP/mcp-server/pull/3045), [#3083](https://github.com/DollhouseMCP/mcp-server/pull/3083), [#3084](https://github.com/DollhouseMCP/mcp-server/pull/3084), [#3086](https://github.com/DollhouseMCP/mcp-server/pull/3086), [#3089](https://github.com/DollhouseMCP/mcp-server/pull/3089), [#3101](https://github.com/DollhouseMCP/mcp-server/pull/3101))
- Strengthen regression evidence for native credential-comparison result propagation, denied-login Argon2 work, causal OAuth PID publication and lock/stop-helper failures. Add safe sanitizer timing diagnostics and baseline cache query/byte/parse counters. These tests and diagnostics do not establish a general performance guarantee or erase prior failures. ([#3076](https://github.com/DollhouseMCP/mcp-server/pull/3076), [#3096](https://github.com/DollhouseMCP/mcp-server/pull/3096), [#3098](https://github.com/DollhouseMCP/mcp-server/pull/3098), [#3099](https://github.com/DollhouseMCP/mcp-server/pull/3099), [#3102](https://github.com/DollhouseMCP/mcp-server/pull/3102), [#3115](https://github.com/DollhouseMCP/mcp-server/pull/3115), [#3125](https://github.com/DollhouseMCP/mcp-server/pull/3125))
