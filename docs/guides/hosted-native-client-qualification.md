# Native client import qualification

Status on 2026-09-26: the four payload generators are implemented and decoded in tests. Kiro IDE and LM Studio have published native import schemas, and their in-app handoffs are available with a separate manual route. Goose Desktop documents a Streamable HTTP extension deep link, but the guide uses manual setup while its first-install OAuth behavior is checked. Cherry Studio's import schema is confirmed in source on `main`; its guide stays manual until a released build is pinned and tested. None of the four has yet completed a Dollhouse OAuth and real tool-call acceptance run. This does not qualify local permission hooks or host audit.

The import links encode only a validated same-origin hosted endpoint and a restricted connection name. They carry no credentials, arbitrary command, header, or auto-approval request. Users must review the imported entry, authorize in the browser, and check the current session; opening a link is not proof of connection. The manual paths preserve existing client entries. Track end-to-end work under [#2809](https://github.com/DollhouseMCP/mcp-server/issues/2809) and client-specific qualification issues.
