HTTP/container and console composition, direct AgentManager memory resolution, complete writer exclusion, cold admission, owner eligibility and final capacity/session/restart proofs remain separate prerequisites under #2998/#2906/#2907.

The nested CRUD handler consumes only an authentic resolved operation from its own provider; it cannot accept a structural manager or recapture a different invocation. Gatekeeper metrics, verification state and rate limiters stay owned by the original AQL handler. No shared handler registry or current-manager field is reassigned.

The reviewed constructors then allocate inert services and caches; they do not initialize/load/seed/repair memory, apply content/candidate changes, persist or qualify boot. Existing persona initialization for Gatekeeper policy lookup retains its ordinary ordering. Trusted dependency construction must remain inert. Ordinary standalone/file manager watchers remain supported.

Configured Agent/Execute dispatcher routes currently refuse before the shared AgentManager's independent cached-memory resolver can run. This includes execution continuation and handoff resume. It is an interim refusal, not completed agent wiring or a proposed final production capability restriction. Final composition must bind the actual agent memory dependency or have any final restriction separately reviewed. Ordinary fixed-handler call forms retain their behavior.

The owner stores no current invocation; each queued/failed entry carries its exact manager, original context and originating binding check. Composed legacy clear with retained sole-copy work refuses before altering it; ordinary clear and guarded candidate-based immediate clear keep their contracts. A check cannot cancel an already-started save or imply rollback. Session cleanup and handler disposal do not prove global drain, cross-process exclusion or crash durability.
