# Hono Node adapter security refresh — November 3, 2026

The fresh production audit of PR #3134 at `93e366e634633e6918fc7753726a8b39eec6b269` reports one Moderate advisory, with entries for `@hono/node-server` and its SDK parent. [GHSA-rmxm-3fg6-px4f / CVE-2026-118663](https://github.com/honojs/node-server/security/advisories/GHSA-rmxm-3fg6-px4f) affects versions `>=1.19.10 <2.1.3`: static middleware can decode an already routed path again, allowing a malformed path to bypass middleware protecting a static prefix. There is no observed application import of this static middleware, but the affected dependency is retained and is updated rather than suppressed.

Change the existing exact override from **1.19.15 to 2.1.3**, the lowest official fixed release. The installed SDK 1.32.0 already declares `^1.19.9 || ^2.0.5`; no SDK update or incompatible override is needed. The new Node floor `>=20` matches this project's supported floor, its Hono peer remains `^4`, and it adds no runtime dependency. Standard scripts-disabled npm resolution changes exactly one lock record, with no added or removed records and no other retained version or integrity change. Safety manifests and lock remain unchanged.

## Verification and limits

Two new tests use an actual Node listener, Hono routing and static middleware on loopback with private temporary fixtures. Normal and encoded protected paths remain 401; `/static/%%36%31dmin/secret.txt` returns 404 without the private fixture; an ordinary encoded-space filename remains readable. Literal-percent filenames default to refusal and remain available through the explicit public-file option. An isolated negative control temporarily selected the SRI-verified old installed package: both tests failed, including HTTP 200 for the crafted protected path. The selected 2.1.3 tree was restored; both tests pass. This control changes no tracked source, manifest or lock.

Separately, **six existing SDK/application HTTP suites pass all 121 tests**: transport parity, full smoke/CRUD, OAuth HTTP authentication, stream keepalive, active POST and keepalive/drain. They exercise the real SDK Node adapter, session/authentication flow and streaming behavior rather than substituting the static-path regression for protocol compatibility. Scoped lint passes. The fresh production npm audit reports **zero findings** after this correction. These are local Node 24.16.0 results; database tests were not selected, and no PostgreSQL, external OAuth provider or production service was accessed.

The November 3 full development audits contain additional Moderate glob/minimatch findings beyond the previously accepted LOW deepmerge residual; this correction does not accept or suppress them.
