Tracking: [#2908](https://github.com/DollhouseMCP/mcp-server/issues/2908), under the exact-version policy in [#2452](https://github.com/DollhouseMCP/mcp-server/issues/2452). ## Finding and exposure

The root manifest pins `fast-uri@3.1.6` as an exact transitive override. A fresh `npm audit --json` returned 2 high package paths (`fast-uri` and inherited `ajv`), 19 moderate, 1 low, 0 critical. The two underlying high advisories are [GHSA-qw65-cvwx-89v3](https://github.com/advisories/GHSA-qw65-cvwx-89v3) (unvalidated component port changes serialized authority) and [GHSA-58mr-gqgx-xq4g](https://github.com/advisories/GHSA-58mr-gqgx-xq4g) (unbalanced bracket host disagrees with the eventual HTTP-client host). GitHub marked both as reviewed on September 28, after the previous high-cohort qualification in #2829. #2837 continues to own the moderate/low findings.

`npm ls fast-uri ajv --all` shows the production-installed chain `@modelcontextprotocol/sdk@1.27.1 → ajv@8.18.0 → fast-uri@3.1.6`, including the `ajv-formats → ajv` branch. Installed AJV imports `fast-uri` as its URI resolver; the SDK's AJV provider compiles/caches JSON Schemas and `$id` references. Repository source search found no direct `fast-uri` import. The verified use is schema URI resolution, while the advisory attack paths require an untrusted component port or an unbalanced-bracket host to drive outbound host policy/request routing. Hosted exploitability is unproven, not ruled out. Production package presence and the high audit failure are confirmed.
