All five releases exceed the repository's 21-day policy. The tracked manifest records each exact registry URL, SHA512 SRI, SHA256, source git head, repository, publisher and registry signing key. The exact new tarballs' registry artifact signatures were cryptographically checked during preparation. This verifies registry artifact identity, not an independent reproducible source build or SLSA attestation. Registry version records are available at `https://registry.npmjs.org/<name>/<version>`; upstream commits are identified in the manifest. Each old/new runtime dependency declaration is identical and every existing consumer range accepts the new version. The preparer refuses changed originals, consumers, dependency closure or unexpected duplicate copies.

The build-only preparer downloads only those five fixed URLs, without redirects or package scripts. Each download has a 30-second deadline and 2 MiB compressed limit. Integrity is checked before parsing. The existing tar reader is used only to read bytes; no tar filesystem extraction API is used. Decompressed data is limited to 8 MiB, each file to 1 MiB, and each archive to 1,024 entries. Absolute/traversal/normalized-alias paths, duplicate paths, file-parent collisions, links, special/ignored entries and extended metadata refuse before any replacement. All five payloads are validated first. Complete before/after path, file hash, mode and symlink inventories require every path outside the five package directories to remain exact. The installed `.dollhouse-security-patches.json` retains that inventory and patch provenance. No downloaded archives or staging directories remain in output layers.

The original official Node base layers still contain their historical npm bytes. This changes the effective merged filesystem and does not claim to erase inherited layers. The separate all-layer exclusion of safety development dependencies remains required and unchanged.

The Docker build executes real offline npm pack and npx of a generated script-free synthetic binary, with private HOME/cache and package scripts disabled. Additional checks exercise minimatch/brace expansion, socks' resolved ip-address, @npmcli/query's actual selector parser, and node-gyp's resolved undici through an in-memory mock dispatcher. Unit controls exercise unsafe archives, tampering, unexpected originals/ranges/closure, duplicate leaves, staging collisions and exact untouched bundle state. Local proof using the actual prior image-extracted npm11.19 bundle and exact new artifacts passed on local Node24.16; this is distinct from the pending final native image and all-severity scan qualification.
