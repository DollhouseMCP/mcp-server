# Manual macOS performance diagnostic

This branch-local Core workflow is a diagnostic recipe, not a shipping workflow replacement. It is manual-only and permits attempt 1 on the named branch. The tool checkout uses the dispatch SHA; the separate target checkout is fixed at `4f20b5790d5a7b1c28a698e25796c7aa641c68b5`. Admission checks the source hashes, clean checkouts, reported macOS major 26, native arm64, Node 20.20.2 and npm 10.8.2. A mismatch or missing required fact refuses before npm install, build or performance. The exact macOS patch/build, image and runner version are recorded observations, UNKNOWN when unavailable; they do not gate admission. Image metadata is not physical-host or binary attestation.

The future workflow uses the existing Core checkout, setup-node and upload-action pins, `npm ci --ignore-scripts`, `npm run build` and Jest cache clear. It runs the entire existing performance command once, adding the original setup followed by the diagnostic setup and JSON output. Original config, assertions, workloads, scheduling policy and budgets remain; actual suite and case timestamps are retained in Jest JSON. The original Core Jest cache restore is omitted, and cache clear is retained. The performance npm script replaces the job's NODE_OPTIONS with `--experimental-vm-modules --no-warnings`; worker flags are recorded. No retry or explicit warmup is added.

The observer checks the exact target test path before app imports or hooks. Only that file receives call-through wrappers; the other suites incur the setup path check. CPU is process-wide, and recorded spans are nested and inclusive, not additive or exclusive. Metadata, CPU sampling and the async Promise continuation add overhead; span clocks omit some setup and record overhead that benchmark timers include. Heap/resource snapshots do not establish GC event timing; that remains UNKNOWN. Missing expected target coverage or overlapping/incomplete spans makes the diagnostic inconclusive.

The original ordinary unit shard is omitted. Its earlier activity may have affected host state, so this controlled full-performance run is not an identical historical replay or release qualification. Artifacts include only the listed receipts, raw test output, Jest JSON and observer facts; no environment dump, token, npm configuration, source archive or node_modules is uploaded. Source and host admission, the performance exit and expected full-suite coverage must all succeed; failures are retained rather than retried.

No workflow dispatch, setup download, install, build or performance run is authorized by the existence of this recipe. A later explicit owner grant must bind the reviewed tool commit, target, branch, one attempt, conditional image admission and bounds before any publication or dispatch.
